# References Artifact Index

Use this folder only for sanitized, website-ready reference artifacts that should appear in the `04 References` tab.

Artifact convention:
- Put clean PDFs, HTML summaries, or approved source notes in this folder.
- Add or update the matching entry in `src/main.js` under `referenceArtifacts`.
- Keep each entry source-backed: source, date or context, permission status, and interview use.

Do not put raw `.msg` files, screenshots with contact details, shortcuts, email headers, phone numbers, or unredacted customer names in this public folder. Keep originals in `Raw Data/Resume References/`.

Avoid invented recommendations. Use exact approved language or a neutral privacy-safe summary backed by a private source artifact.
