# References Artifact Index

Use this folder for reference PDFs, email exports, and short source notes that should appear in the `04 References` tab.

Artifact convention:
- Put PDFs or saved emails in this folder.
- Add or update the matching entry in `src/main.js` under `referenceArtifacts`.
- Keep each entry source-backed: source, date or context, permission status, and interview use.

Avoid invented or paraphrased recommendations. Use exact approved language or a neutral summary with the source artifact linked.
